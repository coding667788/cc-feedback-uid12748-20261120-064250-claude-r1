实现本地联合登录服务的模拟器。每个租户配置多个已登记身份提供方、精确回调字符串和多套客户端策略，全部为本题合成数据。发起挑战固定租户、提供方、客户端、发起设备代数、回调、权限集合、验证值的 SHA-256 和到期时刻。回调输入包含绑定挑战的模拟已验签声明与唯一声明 ID；确认提供方、受众、主体及时间后才能生成唯一会话兑换凭据。声明中同名外部主体跨提供方和跨租户都独立。

兑换时须验证发起设备仍属同代、回调和客户端相同、验证值摘要相同、目标权限与挑战的许可完全匹配，并重新读取提供方、主体和客户端当前状态。吊销、客户端权限收缩及设备重置须使相应的未兑换凭据失效，已经失效的凭据不能通过重复确认复活。失败兑换不消费凭据。用 SQLite 使声明一次消费、兑换凭据一次消费、会话及持久请求回执各自与对应阶段同事务，展示两个阶段独立重启时的结果。

让独立进程之间固定“重复回调争用”“权限收缩先于兑换”“旧设备回调先发后到”三个交错；终止自己的写进程于兑换已写会话但未提交以及已提交未返回，重启后核对同请求回执、不同请求消费结果和会话总数。覆盖假定有效但不属于目标挑战的声明、同号跨客户端、恰好到期以及完整失败原子性。用独立参考规则核对合成输入和输出。

在 Windows 原生 Python 3.12、标准库和 CPU 环境下实现，全部输入自行合成，离线测试。交付源码、README、可重放 cases.json 和自动化测试。提供 python -m solution --input cases.json --output result.json 与 python -m unittest discover -s tests -v。测试须断言具体结果，README 写明规则、输入输出、错误码和实测结果。
